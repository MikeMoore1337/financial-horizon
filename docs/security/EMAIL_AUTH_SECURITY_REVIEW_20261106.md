## Остаточные риски

1. Финансовые записи в IndexedDB пока не шифруются за счёт входа в аккаунт и не синхронизируются между устройствами. Человек с локальным доступом к браузерному профилю может их прочесть. UI-изоляция - не шифрование диска.
2. Проверка CodeQL и Bandit независима от реализации, но не эквивалентна security-ревью отдельным специалистом.
3. Успешная приёмка SMTP специальным тестовым адресом Resend не доказывает получение письма пользователем.
4. Регистрация для широкой публики ещё не включена намеренно. Не снимать canary без отдельного review и решения владельца.

## Критерий закрытия Issue #8

Статус - BLOCKED до независимого ревью и фактического теста получения писем в реальном inbox; запрещено считать эти условия выполненными только по автоматическим тестам. Публикуемые материалы не должны содержать личные IP из allowlist, email реальных пользователей, токены, пароли или секреты.
