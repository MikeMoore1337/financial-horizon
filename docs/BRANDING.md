# Фирменные ресурсы

Выбранный владельцем логотип: синий/мятный знак трёх столбцов над дугой горизонта. Он адаптирован для светлой и тёмной тем.

- assets/brand/logo-light.svg и logo-dark.svg - горизонтальная версия.
- assets/brand/logo-compact-light.svg и logo-compact-dark.svg - версия в навигации.
- assets/brand/symbol.svg и favicon.svg - знаки без текста.
- assets/brand/favicon-16/32/48/64.png, favicon.ico - браузеры.
- assets/brand/pwa-192.png, pwa-512.png, pwa-maskable-512.png, apple-touch-icon-180.png - установочные ресурсы.

Исходные SVG перенесены с верификацией SHA256. Растровые версии воспроизведены из них в Edge/Chromium. Интерфейс не загружает внешние шрифты или изображения. Service worker кеширует только файлы оболочки, не пользовательские финансовые данные.
При будущей замене логотипа нужно обновить PWA-кеш и проверить установку приложения в Safari.
